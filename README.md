## 服务架构

项目包含以下核心服务单元：

1. **Chat Interface Service** - 聊天界面服务
2. **Access Control Service** - 访问控制服务
3. **Document Repository Service** - 文档仓库服务
4. **AI Orchestration Service** - AI编排服务
5. **Communication Analytics Service** - 通信分析服务

详细设计文档请查看 `hackathon-2026-01-26/inception/units/` 目录。
